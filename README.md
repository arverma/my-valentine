# Valentine Week

Valentine Week site (7–14 Feb): one day per view, photo and YouTube Shorts. Optional floating music and a toast on photo click.

**Run:** Open [index.html](index.html) in a browser, or use a static server (e.g. `npx serve`).

**Create your own page:** Edit **[config.js](config.js)** only. Set names, photo URL, day labels and YouTube video IDs, music tracks, placeholder messages, and optional tweaks (emoji lists, counts). Add your image in `images/` and audio in `music/`, and point `photoUrl` and `musicTracks[].src` to them. You do not need to edit [script.js](script.js) or [index.html](index.html) for standard customisation. No build step.
