# Valentine Week

Valentine Week site (7–14 Feb): one day per view, photo and YouTube Shorts. Backward navigation only. Optional floating music and “I love you” toast on photo click.

**Run:** Open [index.html](index.html) in a browser, or use a static server (e.g. `npx serve`).

**Customise:** Edit `PERSONAL`, `DAYS`, `MUSIC_TRACKS`, and related config at the top of [script.js](script.js); add or replace audio in the `music/` folder. No build step.
